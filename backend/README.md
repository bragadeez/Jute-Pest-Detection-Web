# Jute Pest Detector - Backend API 🐍

This is the FastAPI backend for the Jute Pest Detection web application, serving an improved VGG-19 classification model and visualizing predictions using LIME Explainable AI (XAI).

## 🚀 Deployed on Hugging Face Spaces
This repository is configured to deploy directly to Hugging Face Spaces using the custom `Dockerfile`.
